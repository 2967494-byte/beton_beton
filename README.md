# 🏗️ ZOOMLION Бетононасосы — Веб-сайт и Каталог спецтехники

Современный веб-сайт с интерактивным каталогом автобетононасосов ZOOMLION (от 32м до 62м на шасси SITRAK, SCANIA, ISUZU), калькулятором лизинга и админ-панелью для управления товарами.

## 🚀 Особенности проекта

- **Премиальный светлый дизайн (Light Theme):** Чистая палитра, адаптивная верстка, типографика Google Fonts (*Outfit* & *Inter*), плоские векторные SVG-иконки.
- **Интерактивный каталог:** Фильтрация в реальном времени по высоте подачи стрелы, марке шасси, статусу наличия и текстовому поиску.
- **Модальные окна ТТХ:** Подробный разбор характеристик каждой модели, гарантийных условий и контактов менеджеров.
- **Калькулятор лизинга:** Выбор размера аванса (10%-50%), срока (12-60 мес) и автоматический расчет ежемесячных платежей.
- **Админ-панель (`admin.html`):** Редактирование, добавление и удаление товаров, изменение цен, фото, выгрузка `models.json` и синхронизация с витриной.
- **Готовая папка `deploy/`:** Собранный дистрибутив сайта для заливки на хостинг.

## 📁 Структура проекта

```text
.
├── index.html                                    # Главная страница (витрина)
├── admin.html                                    # Админ-панель (без кнопки на сайте)
├── deploy/                                       # Готовые файлы для хостинга
├── src/
│   ├── css/style.css                             # Дизайн-система и стили
│   ├── js/app.js                                 # Логика витрины и фильтрации
│   ├── js/admin.js                               # Логика админ-панели
│   └── data/models.json                          # База данных моделей АБН
└── README.md
```

## 🛠️ Запуск локально

Для просмотра запустите любой локальный HTTP-сервер в папке проекта:

```bash
# Использование встроенного сервера Python:
python -m http.server 8080
```

Затем откройте в браузере:
- **Сайт-витрина:** [http://localhost:8080](http://localhost:8080)
- **Админ-панель:** [http://localhost:8080/admin.html](http://localhost:8080/admin.html)
